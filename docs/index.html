安装与授权

第一次使用需要四步，之后打开就能直接用。

  1. 下载 APK
    从 GitHub Releases 下载 sodaHelper.apk。
  2. 允许未知来源
    系统提示时选择允许，部分 ROM 需要关闭纯净模式。
  3. 开启无障碍
    设置 → 无障碍 → 已下载的应用 → 汽水助手 → 开启。
  4. 开启悬浮窗与后台运行
    应用管理 → 汽水助手 → 显示在其他应用上层；电池 → 允许后台运行。
OPPO / ColorOS 建议同时允许自启动。更新 APK 前先关闭无障碍，安装完成后再重新开启。

常见问题

关于权限、封号和更新的说明。

需要 root 吗？

不需要。工具使用 Android 无障碍服务模拟点击，不修改汽水音乐安装包。

支持哪些系统？

最低 Android 7.0，主要在 Android 11 的 OPPO 设备上验证。不同 ROM 的后台限制不同，建议允许自启动和后台运行。

会不会封号？

自动化操作可能违反汽水音乐用户协议，存在账号被限制的风险。建议仅个人自用，不要多账号刷量或对外售卖。

为什么需要无障碍和悬浮窗？

无障碍用于读取页面控件和模拟点击；悬浮窗用于显示轮次、进度和停止按钮。工具不会读取账号密码，也不会上传数据。

更新后无障碍失效了？

覆盖安装会重置无障碍授权。重新在系统设置里开启一次即可；建议更新前先关闭无障碍，安装后再开启。
